# starboy1968.github.io

Portfolio site for Rashon Alsberry. Plain HTML and one CSS file; no build step, no JavaScript, no external requests.

To publish: push `index.html`, `style.css`, `favicon.svg`, and `assets/` to the `Starboy1968/starboy1968.github.io` repo and enable GitHub Pages on the `main` branch. `_src/` and `_preview/` are local working folders and are not needed on the site.
